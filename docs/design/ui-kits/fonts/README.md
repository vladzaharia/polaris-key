# Mockup fonts

The mockups load Rubik (variable, wght 300–900) and JetBrains Mono (variable, wght 400–600) from
the shipped package, `packages/brand/fonts/fonts.css` (UK-01 moved them there with the generator
and drift gate). Only the Android board's icon font lives here:

- `material-symbols-rounded-subset.woff2`: Material Symbols Rounded, only the glyphs the Android
  board uses. Apache License 2.0.
