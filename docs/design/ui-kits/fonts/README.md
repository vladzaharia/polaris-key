# Mockup fonts

Used only by the UI-kit mockups in this folder; UK-01 moves the shipped copies into
`packages/brand/fonts/` with the generator and drift gate.

- `rubik-var-latin.woff2`: Rubik variable (wght 300–900), latin subset. SIL Open Font License
  1.1 (see `packages/brand/fonts/OFL.txt`).
- `jetbrains-mono-var-latin.woff2`: JetBrains Mono variable (wght 400–600), latin subset. SIL
  Open Font License 1.1. The kit mono for keys, user codes and hashes (UI-KITS §2.1).
- `material-symbols-rounded-subset.woff2`: Material Symbols Rounded, only the glyphs the Android
  board uses. Apache License 2.0.
