How a device’s entitlements add up
From the one license the device runs on: its tier, then that license’s overrides, then its add-ons, then the platform entitlements from its limits. A paid add-on is never turned off by a tier or license value. Devices still receive every entitlement as before, so the game’s code doesn’t change.
