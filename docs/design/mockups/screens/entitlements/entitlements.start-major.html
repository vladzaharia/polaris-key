Start a 5.x tier

Pro 5 starts as a copy of Pro 4 that covers 5.x. Pro 4 doesn’t change: its 64 licenses keep running 4.x.

Pro 5
pro-5
pro-5 belongs to an archived tier, Pro 5 preview. Ids are never reused: try pro-5-2026.
5.x
Covers 5.0.0 up to, but not including, 6.0.0, with 5.x betas for licenses on the beta track. Like Pro 4, no end date.
Limits5 devices, 30 offline days, stable and beta tracks IncludesLossless audio, stem separation, 250 synced crates, 100 MB of Cloud Sync storage Profilepro, 3 Managed config values
Untick a group to start it empty: platform default limits, no entitlements, no profile.

No license moves on its own. When a Pro 4 holder upgrades, change their license’s tier to Pro 5, or issue Pro 5 licenses from DJDL’s billing through the admin API. Pro 5 goes just above Pro 4 in list order, so a holder of both runs as Pro 5.
