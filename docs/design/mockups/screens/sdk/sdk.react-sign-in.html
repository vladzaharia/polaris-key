DJDL signs in with the React kit

<PolarisKeyGate> in an Electron window on Windows: the one sign-in form, inline in the Welcome window. The product is the hero, in an accent taken from DJDL’s icon, with no Polaris Key mark. Each step’s body morphs in place under a header that never moves; nothing stacks on the form.

Kit preview · fixture product
DJDL really ships Swift on macOS and Kotlin on Windows (its Integration page). It is drawn here as an Electron build only to show the React kit inside the Electron kit (UK-06), with DJDL’s facts: Sign-in on, licenses through its groups, sold on its own site.
