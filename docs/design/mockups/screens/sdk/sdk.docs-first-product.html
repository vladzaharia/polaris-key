Your first product

Examples use Tidewater Studio.

About 15 minutesUpdated Oct 7, 2026
  1. 1

    Create the product

    Choose New product in the console. Its Integration page opens.

    Name and slugTidewater Studio, tidewaterThe slug can’t change later
    What it’s forLicensing and Managed config to startCloud Sync needs Sign-inCommerce needs Licensing
    PlatformsmacOS and Windows

    Keep the product in your repository? Run pkey init, push, and link the repository on the product’s Settings.

  2. 2

    Add the SDK

    In your app’s folder, run the command Integration shows. It adds the SDK, writes polaris-key.json and pins Tidewater’s keys.

    NodeReactPythonSwiftKotlinGodot5 more
    $ pkey sdk add swift --product tidewater \
    --expect <fingerprint from Integration>
    What polaris-key.json holds

    No terminal? Download polaris-key.json from Integration and add the SDK with your package manager: Install from the package feeds

  3. 3

    Start the SDK

    fromConfig() reads polaris-key.json.

    boot() checks the license, syncs managed config and registers the device.

    NodeReactPythonSwiftKotlinGodot5 more
    Drop-in UI kit

    Ready screens for sign-in, activation and device limits.

    ContentView.swift
    import PolarisKeyUI

let pk = try await
  PolarisKeyClient.fromConfig()

ContentView()
  .polarisKeyGate(pk)
    The SwiftUI kit
    Your own UI on the library

    Call the SDK and draw every screen yourself.

    App.swift
    import PolarisKey

let pk = try await
  PolarisKeyClient.fromConfig()
await pk.boot()

if await pk.isLicensed() {
  openProject()
} else {
  showSignIn()
}

If something’s missing

Waiting
The console steps are done. Use the feature once in the app: sign in, or check for updates.
A key doesn’t match
Run pkey sdk add again, or download polaris-key.json again from Integration.
Still stuck
Run a debug build. On the first refusal it prints what’s missing and where to fix it.
