DJDL activates with a key in the React kit

Have a license key? morphs the same form into the key field. Every answer from Polaris Key lands in the same place under the field. A key keeps the license floating; when it is already on all its devices the form offers Replace a device inline, and afterwards it recommends keeping DJDL in an account, once, without making it a step.

Kit preview · fixture product
As on sdk.react-sign-in: DJDL really ships Swift on macOS and Kotlin on Windows. It is drawn as an Electron build only to show the React kit; its facts (Cloud Sync on, Standard on 5 devices) are DJDL’s.
