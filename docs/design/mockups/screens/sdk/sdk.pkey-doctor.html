How it behaves

  • Exit 1 while anything is to do
  • --no-color keeps the words
  • --product defaults to .pkey/product
  • --base-url defaults to PKEY_BASE_URL
  • Console links follow the base URL
  • Outside a repository it checks sign-in, the base URL and polaris-key.json in this folder
