Updates

How installed copies of DJDL update themselves. Each updater shows Verified after its first real update check.

From DJDL’s builds macOS · Apple silicon, Intel Windows · x64 (.msi)

macOS · Sparkle

4.2.2 on stable and 4.3.0-beta.3 on beta, for Apple silicon and Intel.

12 signature failuressince Oct 9, 10:20

Setup

Sparkle signing key
Made with pkey release keys init --sparkle on Oct 7, 11:05. The public half is in .pkey/release.
Signed appcast
Every update in it is signed with that key.
Builds carry the same key
4.2.2 doesn’t: its SUPublicEDKey is different.
DJDL 4.2.2 has the wrong SUPublicEDKey
4.2.2, published Oct 9, was built with kZ8r…Q1c= in its Info.plist, not pJ3m…vWc= from .pkey/release. Copies on 4.2.2 refuse every update Polaris Key signs: 12 tried 4.3.0-beta.3 since 10:20.
To fix it: put the key this prints back in Info.plist and publish 4.2.3. Copies on 4.2.2 can’t update themselves: their owners get 4.2.3 from the download page or Library.
pkey release keys init --sparkle --show-public
Email the 37 people on 4.2.2

In your app

SwiftPolarisKeyUpdateInfo.plistalso required
import PolarisKeyUpdate

// In applicationDidFinishLaunching, after PolarisKey starts.
// Sparkle reads the feed for this license’s release track and
// sends the device’s license token with every check.
let updates = try PolarisSparkle(client: polarisKey)
updates.startUpdater()
Each check carries the device’s license token, so only Customers get updates. Sparkle also needs SUFeedURL and SUPublicEDKey from the Info.plist tab.

UpdaterWinSparklechosen by Ana Lima on Oct 7 Velopack also fits, for apps packaged with vpk. App Installer needs an MSIX build, and DJDL makes an .msi.

Setup

Signing key
The Sparkle key signs Windows updates too.
WinSparkle appcast
Lists 4.2.2 (x64) on stable and 4.3.0-beta.3 on beta.
First update check
Ship a Windows build with this code. It shows Verified after its first check.

In your app

KotlinWinSparkle via JNAC++
// Before DJDL’s main window opens, after PolarisKey starts.
WinSparkle.win_sparkle_set_appcast_url(
    "https://key.plrs.im/djdl/update/stable/winsparkle.xml")
WinSparkle.win_sparkle_set_eddsa_public_key(
    "pJ3m0QxR9vT2kLw8yHc4Zb6N1sFq7vWc=")
WinSparkle.win_sparkle_set_http_header(
    "Authorization", "Bearer " + polarisKey.updateToken())
WinSparkle.win_sparkle_init()
The header carries the device’s license token, so only Customers get updates. Licenses on beta read update/beta/winsparkle.xml.

Not shown: zsync for Linux AppImages and Play in-app updates for Android, because DJDL doesn’t ship there, and the Godot updater, because DJDL isn’t a Godot game. Plan a platform in Settings
