Packages

Package feeds on pkg.plrs.im for the packages DJDL declares in .pkey/release. A declared package gets its feed on the next resync, open to Customers until you change it on Access.

DJDL declares no packages yet

Declare a library or image in .pkey/release and its feed appears here on the next resync, open to Customers. There’s nothing to turn on.

.pkey/release
deliverables:
  npm.sourcekit:
    kind: package
    ecosystem: npm # npm | pypi | swift | maven | oci | godot
    name: "@djdl/source-kit"
    artifacts:
      tarball: { match: "dist/npm/djdl-source-kit-*.tgz" }
Then publish each version from CI with pkey release publish --deliverable npm.sourcekit --dir dist/npm.
