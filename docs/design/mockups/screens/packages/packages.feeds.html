  - run: pkey release publish --deliverable npm.sourcekit --dir dist/npm
  - run: pkey release publish --deliverable npm.crateschema --dir dist/npm
  - run: pkey release publish --deliverable pypi.crates --dir dist/pypi
+ - run: pkey release publish --deliverable swift.sourcekit
+     --dir dist/swift --version ${{ github.ref_name }}
Each package publishes in its own step, so the Swift one needs this step after the npm and PyPI ones. dist/swift is where swift package-registry publish --dry-run writes.

On your machine

Your personal token installs every package you can read, in every product. This command signs you in, makes a packages-only token and sets up every package manager DJDL’s feeds use.

pkey feeds setup --write
