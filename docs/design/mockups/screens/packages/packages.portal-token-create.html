Set up your package managers

In your home folder, never a repository.

pkey feeds setup --write

Signs in, makes a token and sets up npm, pnpm, Yarn, Bun, uv, pip and Docker

Copy the npx commandpkey CLI docs

Or by hand

npm, pnpmYarnBunuv, pipDocker
# ~/.npmrc
@djdl:registry=https://pkg.plrs.im/npm/djdl/
@diceroll:registry=https://pkg.plrs.im/npm/diceroll/
//pkg.plrs.im/npm/:_authToken=${PKEY_PACKAGES_TOKEN}
Only @djdl and @diceroll come from here; everything else stays on npmjs.com. Set PKEY_PACKAGES_TOKEN to your token.
