Set up your package managers

One setup covers DJDL and Diceroll. It never goes in a project, so your token stays out of your repositories.

pkey feeds setup --write
Signs in, makes its own packages token and sets up npm, pnpm, Yarn, Bun, uv, pip and Docker in your home folder. pip’s index is added per project. Don’t have pkey? With Node 22, npx runs it once without installing it. Copy the npx command · Docs: the pkey CLI
or by hand
npm, pnpmYarnBunuv, pipDocker
# ~/.npmrc
@djdl:registry=https://pkg.plrs.im/npm/djdl/
@diceroll:registry=https://pkg.plrs.im/npm/diceroll/
//pkg.plrs.im/npm/:_authToken=${PKEY_PACKAGES_TOKEN}
Only @djdl and @diceroll packages are looked up here; everything else stays on npmjs.com. Set PKEY_PACKAGES_TOKEN to your token.
