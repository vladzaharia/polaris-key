Apple Music developer token
Integrations
Lets DJDL match tracks against Apple Music. Only operators see this; a minted token is never listed in the app.
Setting
A value DJDL reads. You decide whether people can change it.
Secret
Write-only here. DJDL reads it in code; it’s never listed.
Minted token
Signed on request from a recipe. Never stored.
Code only. DJDL asks for a fresh token with mintToken("applemusic") each time it needs one. A minted token isn’t stored, isn’t listed in DJDL’s settings and doesn’t sync.

Polaris Key signs the token with your key; the key never leaves Polaris Key.
