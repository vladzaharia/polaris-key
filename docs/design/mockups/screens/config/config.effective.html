Then, on each device

What DJDL does with this list on each Mac and PC, in this order.

  1. A lock wins
    Read-only and Hidden values are final: run.concurrency is 6 on every device.
  2. Then the person’s own choice
    What Mara picks in DJDL’s settings, kept the same on her other devices by Cloud Sync.
  3. Then the computer’s environment
    Values set on the computer itself, such as by an IT admin.
  4. Then this list
    The values on this page.
  5. Then DJDL’s fallback
    The default written in DJDL’s code.
For example, quality.floor is Editable at flac. If Mara picks mp3-320 in DJDL, her choice wins on all three of her devices.
