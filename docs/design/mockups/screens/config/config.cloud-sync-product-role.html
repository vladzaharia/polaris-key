In your game

Settings sync with no extra code. Saves take one call.

GDScriptGodotSwiftiOSKotlinAndroid
# Settings sync on their own.
PolarisKey.config.set_value("audio.music", 0.6)

# Save slot 1, with what the load screen shows.
var saves := PolarisKey.cloud_sync.saves
await saves.write("slot-1", state.to_bytes(), {
  "playtime": 5400, "progress": 0.42,
  "chapter": "Harbor",
})

# Two devices disagree: let the player pick.
saves.conflict.connect(_on_save_conflict)
Written for Diceroll’s saves template and its setting audio.music.
