Set up selling on Steam

Three steps in Steamworks and Store connections. Each one ticks itself when Polaris Key sees it done; nothing here asks you to type an id.

1Create DJDL’s app in Steamworks
Steamworks gives DJDL an App ID after Example Audio pays the Steam Direct fee for it. Polaris Key can’t do this step for you.
2Add Example Audio’s publisher key
In Steamworks, create a Web API publisher key under Users & Permissions → Manage Groups, then add it in Platform → Store connections. You add it once for every product.
3Assign the app to DJDL
With the key in, Store connections lists Example Audio’s Steamworks apps. Pick DJDL’s; Polaris Key reads its App ID and DLC from Steam.
Waits for steps 1 and 2
Polaris Key checks Steamworks every 10 minutes · last checked 10:38

What Steam can sell

DJDL itself, as a paid app. A purchase makes or extends the buyer’s license.
Add-ons as DLC, such as Stem separation.
No subscriptions: DJDL Pro yearly stays on the App Store and your site.
No price API: you set Steam prices in Steamworks.

Shipping builds to Steam is set up on its own, on Releases.
