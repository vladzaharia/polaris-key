Integration

Connect DJDL’s app to Polaris Key. Each feature lists what’s left in the console, the code for your SDK, and Verified for each platform once an SDK reaches it.

Your app

Swift on macOS and Kotlin (Compose Desktop) on Windows, picked from DJDL’s platforms and the SDKs seen so far.

Add the SDKOne commandBy hand

Terminal
$ pkey sdk add swift --product djdl \
    --expect djdl-2026@sha256:3f9a0c7d2b8e41f6a9c35d0e7b1f4a28c6e9d3b7051f8a2e4c6b9d0f3a7ee41b

Adds PolarisKey from pkg.plrs.im, writes polaris-key.json and pins DJDL’s signing and release keys. Run it in the Xcode project’s folder; for Windows, run it again with kotlin.

5 devices, lifetime, 30 days offline.
Access policy
Members of the members group get Standard when they sign in.
Test license Optional
A Standard license to try the gate with. The key shows once.

In your app

SwiftmacOSKotlinWindowsMore
import PolarisKey

let client = try await PolarisKeyClient.fromConfig()
await client.boot()

if await client.isLicensed() {
  let vpn = await client.license.isEntitled("polarisVpn")
  routeThroughVpn(vpn)
} else {
  showActivation() // or PolarisKeyUI’s gate view
}
Written for DJDL: its entitlement polarisVpn, pins from polaris-key.json.

Sign-in

Let people sign in to DJDL with their Polaris Key account.

Console ready

In the console

Connection
Pocket ID, the platform connection, with the members and admins groups.
Sign-in surfaces
Browser sign-in on macOS and Windows. Polaris Key sets up the return to the app, so there’s nothing to enter.

In your app

SwiftmacOSKotlinWindowsMore
// Opens Polaris Key sign-in in the browser and
// comes back when the person has signed in.
try await client.identity.signInWithBrowser()

if let me = await client.identity.current() {
  showAccount(me.screenName)
}
