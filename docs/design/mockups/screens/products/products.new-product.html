New product

Three steps. Nothing is created until you press Create.

  1. Repository or nameDiceroll, no repository
  2. What it’s forFeatures, platforms, Free tier
  3. CreateReview, then create

What is Diceroll for?

Choose the features Diceroll uses. Each one says what it turns on. You can change them later in Settings → Features.

Licensing
Gate Diceroll on a license and sell it as tiers and add-ons.
Turns onTiers, licenses and device limits, starting with the Free tier below.
Managed config
Change settings and secrets without shipping a build.
Turns onThe Default profile, catalog v1 and secrets.
Ship builds
Publish releases from CI and deliver them to every store and the download page.
Turns onReleases, channels and in-app updates.
Sign-in
Let players sign in with a Polaris Key account.
Turns onAccounts in the game and the customer portal.
Cloud Sync
Keep each player’s saves and settings the same on every device.
Managed config is chosen Needs Sign-in: choose it first
Commerce
Sell packs and tiers on App Store, Google Play, Steam and itch.io.
Needs Licensing, which is chosen
Turns onOffers, a SKU on each store and one list of purchases.

Where will Diceroll run?

Channels, storefronts and SDK code show only for these. Builds you publish add their platforms on their own.

iOS Android Windows Linux macOS Web
Start with a Free tier
Every license has a tier. Free is lifetime, for 2 devices; change it under Licensing → Tiers.
