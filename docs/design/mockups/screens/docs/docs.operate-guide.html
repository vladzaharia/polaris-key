Help a customer

Export or delete a person's data, or move their license to another person.

Requires: access to Users
Impact
An export contains personal data. Deleting data can't be undone.

Export a person's data

  1. 1

    Open Users, then the person's record.

  2. 2

    Select Export JSON and save the file.

Delete a person's data

  1. 1

    On the person's record, select More actions, then Delete data for this product….

  2. 2

    Type delete, then select Delete data.

Move a license to another person

  1. 1

    On the Licenses tab, select Relink… on the license.

  2. 2

    Under Move to user, enter the customer's support code and a reason, then select Relink license.
