## Goal

The SDK additions the "Pair with a Code" kits need, with no wire change (`PROTOCOL_VERSION` 5, `corpusVersion` 2, `peerMatrixVersion` 1, `copyVersion` 1).

- .15a: V5 §15.12 sentences, the reason vocabularies in `enums.json`, the error descriptions, the two core messages in 9 locales.
- .15b: client-core `NameplateMemory`, the reason and cap types and `dialsLeft`; the append-only `local.nameplateMemory` and `local.joinReasons` corpus sub-sections and the Node runner.
- .15c, .15d: the Node shower, joiner and list. .15e, .15f, .15g: Python, Swift, Kotlin.

## Why

The kits show why a code stopped working, how many dials are left, a renewed code and the paired list without private state. The shower must not reuse a nameplate whose window just closed, so a renewed code is new in every respect.
