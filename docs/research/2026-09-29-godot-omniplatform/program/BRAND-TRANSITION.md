## Decisions

- **B1 Commerce accent = the Distribution green family. No ninth vermilion family.** The `commerce` service slug and routes (CM-29) STAY (behaviour); only the COLOUR changes. CM-29b is re-scoped to 'commerce uses Distribution colours + shopping-bag glyph + Pinned K mark (Commerce requires License)'; the accent-distance floor stays 17.5 (no lowering). REVERSES the owner's 2026-10-08 vermilion choice because the owner's own new guide, site and mockups say green and vermilion reads as an error.
- **B2 Primary action = neutral ink** (dark: action #f6f8ff, label #060912; light: action #060912, label #ffffff) in the CONSOLE, PORTAL and HOSTED SIGN-IN. Danger stays red; accent marks context only (nav marker, links, masthead tile/rule). New token role `action-neutral` (generated via `pnpm gen:brand`). UI KITS KEEP the host/product accent as the primary (DL13); `polaris-key` preset primary is the product accent. Amends BRAND §5.4, ADMIN §2.4, PORTAL §0.2/§0.3.
- **B3 Selected nav = subtle accent fill + 3 px solid inset marker (strengthened), NOT a solid accent pill.** Count badges keep their own status colour inside the selected item. Focus ring violet everywhere (fix ADMIN §2.4 inconsistency).
- **B4 Console shell v2 (from the guide, adapted):** inset canvas (raised, rounded ~18 px, 3 px accent top rule, from 1024 px, full-bleed below; NO glow/wash/gradient); condensed masthead: ONE orientation line (glyph chip + crumbs; no eyebrow repeating the path, never 'Platform' on a product page, no 'WORKSPACE' label), h1 36/44 collections and 32/40 records (phone 24/32) with long-name clamp, 48 px flat service tile only at >=1024 px on feature landing pages (product icon on product Core pages; none on dense data pages), masthead <=140/176 px; section head bands (18/24 titles) WITHOUT numerals (numbers only for ordered steps); route tabs as UNDERLINE tablist (not segmented), fade only when overflowing; table 'workbench' = ONE bordered band for filters + table, 56 px rows (never 76), sentence-case heads, solid-outline chips; tablet = contained scroll in a labelled focusable region with sticky first column; neutral sidebar group labels with a 3 px accent bar; recessed inputs (3:1 border check); dialogs/drawers: 3 px accent top rule + head band, ONE leading glyph (severity for confirmations, subject mark for records), titles <=20/28, no service tile, no rule on destructive/caution dialogs, blurred backdrop with reduced-transparency fallback; bounded measure 72ch; Features table full width. Dashboard split (Needs attention 2/3 + Platform ready 1/3) at >=1280 only; product cover cards 72 px ProductArt banner in Cards view only (hosted art else flat stored tintColor; never read canvas pixels).
- **B5 Ship builds is ONE identity**: Package glyph, Release cyan chrome (rule, tile, nav marker) on Releases, Release tracks, Rollouts, Channels, Packages, Updates, Health; crumb '<Product> › Ship builds › …'. Distribution green stays on Commerce/Sales surfaces; Update tangerine and Packs orange are marketing/docs only (no data-service). Cloud Sync (one page) = one nav row. Non-protocol areas need explicit `data-service` mapping (never 'undefined').
- **B6 Rejected in product chrome:** glows, gradients, washes, coloured shadows, accent-tinted card hairlines/sheet rims (also never under native/forced colors), section numerals, marketing eyebrows/taglines/slogans, display-size h1 in console, 76 px rows, uppercase table heads/eyebrow transforms on identifiers, name painted over art, floating header bar, phone tabs in a second header row (portal keeps bottom bar), chartreuse fills in the core-violet portal, tilted/parallax/looping motion, durations >480 ms, text <12 px, signing/success drawn in accent colour (gold = signing only; accent never = status), forced dark theme, per-component focus colours, accent edge on kit cards/terminal chrome (opt-in token only).
- **B7 Weights 400/500/600** on every surface (DL12); 700 only for the wordmark; console `font-bold` sweep (426 uses) = package. Display scale + display tracking tokens only >=40 px and at most -0.02em in product; marketing may use the site values.
- **B8 Hosted card (Worker HTML) + portal:** neutral ink primary; DL6 neutral callout for ALL refusals (device limit, all-full, email mismatch, key-entry limit) with the fix as the one primary and NO disabled-primary dead end (amber only for 'unsynced changes' on sign-out); 'passport' = neutral SUNKEN identity pane in both themes, two panes ONLY landscape >=960 px, never portrait/tablet-portrait, developer and device on separate lines, no eyebrow, full-width trust-receipt footer, `<img>` art same-origin (widen Worker CSP `img-src` exactly like the app policy via cspImageOrigin()), no inline style/script; key on-ramp and Done header '<Product> · <Developer>' (no 'wants you to sign in'); consent Allow/Deny EQUAL size with scopes listed before the buttons; provider button fills only from Apple/Google/Steam allowed sets, never the host tint; phone-only lilac hairline rejected; sign-in star field stays.
- **B9 P0 SECURITY:** device-code ALWAYS ends with an explicit 'Sign in on <device>?' confirm with Deny when no license-choice/consent step runs (scan is never approval). Design rule, no wire change; the TV keeps seeing 'pending' until confirmed. Device-code page cannot name the product before the code resolves.
