## 0. Owner decisions encoded (binding) and the SP-00 assumption

- **UI-KITS (2026-10-05):** launch locales `en`, `de`, `fr`, `es`, `pt-BR`, `it`, `ja`, `ko`,
  `zh-Hans`; no RTL locale (layouts stay RTL-safe, no RTL fixture). `copy.en.json` stays the one
  source for error and gate copy; `packages/brand/kit-copy/en.json` holds kit-only strings and
  never duplicates a `core.copy` string. The eight packs are produced in UK-02a, `reviewed: false`,
  not a merge blocker. Python UI is Qt plus the terminal (no Tk). Kits read product accent and icon
  only through the `ProductIdentity` seam (HA-13/HA-14).
- **S-16 / I-04:** `license_owned` copy says another account holds the licence, never whose.
  Credentials are entered only on the hosted card (D17), so no kit string asks for a password or an
  email code. Device-code sign-in always ends with "Continue to <App>" on the card (D22); the kit's
  `confirm` state says so.
- **S-17:** Cloud Sync needs sign-in. No kit string offers "add this licence to your account to
  sync" (withdrawn); `CloudSyncStatus` (a should component, no row here) says "Sign in to sync".
- **S-18:** UK-02 adds no setting. The kit `Settings` screen renders customer config
  (`config.list`) only; provenance is text and a locked row reads "Set by {org}".
- **S-19 (model OC):** a licence is an access contract and grants are entitlement reasons. The
  **holder** shown in `AccountAndLicense` is **the account signed in on this device**, or nobody: a
  key-entry device shows its licence only and never the licence owner's account. UI copy spells
  "license" and **never says "grant"** (nor "download grant": it is a download ticket). **`legacy`
  mode is byte-identical**, so every fixture input uses today's result shapes; `grants()`, per-entry
  `expiresAt` and 401 `reason` rows belong to LX-19.
- **SP-00 (assumed as on `plan/SP-00` `eb751244`, approved, not yet on `main`).** UK-02a and UK-02b
  both depend on SP-00, and this plan assumes it lands as written: `conformance/parity/copy.en.json`
  with shape `{copyVersion: 1, locale, fallback, codes, gate, activation}` and `{title, message}`
  entries; the `licenseStatus` and `activationResult` enums; `ui.cli`; the `headless` trait and
  `ui.kit`'s `headless` N/A both kept (SP-00 D6); the manifest `wp` pattern
  `^[A-Z][A-Za-z0-9]*-[0-9]{2}$`; and six generated core copy modules from `gen:constants`. If SP-00
  changes any of these, the matching section here is re-read before UK-02a starts.

## 1. Summary

- **Catalog:** `packages/brand/kit-copy/en.json` (about 220 ICU keys, D5) plus eight locale packs,
  a glossary and `components.json` (each §4.1 component's states and static copy keys). Seven core
  locale packs go beside `copy.en.json` (D4).
- **Generators:** `gen:brand` emits one table per platform: web JSON, Swift `.xcstrings`, Compose
  Resources `strings.xml`, Godot `.po`/`.pot`, a Python module and `.pot`, and a Node terminal
  module. Each carries kit keys plus `core.*` keys (D2, D3).
- **Corpus:** `ui-matrix.json`, with one family per parity row, input → component, state and copy
  keys. The `i18n` and `theme` families pin formatting and theme resolution. It is generated and
  mirrored, with no signed vector touched (D1).
- **Registry:** ten `ui.*` ids. All six manifests mark them `planned`, each owned by that SDK's kit
  package (D8).
- No wire, Worker or deploy change.

## 2. Contract

Nothing changes. `WIRE-CONTRACT-V4.md`, `shared-protocol`, `shared-jws` and `client-core` are
untouched, and `PROTOCOL_VERSION` stays 4. Every fixture input is a value an SDK already returns
(enums from `enums.json`, codes from `errors.json`, stage outcomes from `stage-matrix.json`, update
actions from `update-matrix.json`, rows from `config.list`), or a kit-side value (`ProductIdentity`,
platform, pending action). Deployed clients and Workers see no byte of difference.

## 3. Catalog, generators and registry

There is no `shared-catalog` or `shared-manifest` change, so AGENTS rule 9 is not involved.

### 3.1 Sources (UK-02a, all hand-written, each with a JSON Schema beside it)

- **`packages/brand/kit-copy/en.json`** has the shape `{kitCopyVersion: 1, locale: "en", messages}`,
  where each message is `{value, role, note, variants?}`:
  - `role` ∈ `title`, `body`, `label`, `button`, `menu`, `windowTitle`, `a11y`, `hint`;
  - `note` is the translator context and is required;
  - `variants` is keyed by `macos`, `ios`, `android`, `windows`, `linux`, `web`, `godot`,
    `terminal`, `tv`, and is allowed only on `button`, `menu` and `windowTitle` keys (the verb or
    the casing, UI-KITS §4.7).

  Keys match `^[a-z][A-Za-z0-9]*(\.[a-z][A-Za-z0-9]*)+$`. The first segment is a component
  (`gate`, `boot`, `welcome`, `signIn`, `signInHandoff`, `activate`, `offlineActivation`,
  `deviceLimit`, `devices`, `update`, `updateProgress`, `releaseNotes`, `status`, `grace`,
  `account`, `settings`, `paywall`, `entitlement`, `cloudSync`, `about`, `channel`, `toast`), a
  shared part (`part`, `common`) or `a11y`. **`core` is reserved.** Seed sources:
  - React `packages/sdk-react/src/components/theme.ts`;
  - Swift `PolarisCopy` (`PolarisKeyUI/PolarisTheme.swift`);
  - Kotlin `sdks/kotlin/ui/src/main/res/values/strings.xml`;
  - Godot `ui/copy/pkey_ui_copy.gd`;
  - the hard-coded strings the five audits found.

  Any string already in `copy.en.json` is dropped from the kit bags rather than copied.

- **Arguments** come from a closed set:
  - pre-formatted strings: `{product}`, `{device}`, `{time}`, `{date}`, `{version}`, `{size}`,
    `{total}`, `{org}`, `{method}`, `{store}`, `{min}`, `{max}`;
  - plural integers: `{count}`, `{days}`, `{minutes}`, `{used}`, `{limit}`;
  - the `formFactor` select, with cases `iphone`, `ipad`, `mac`, `phone`, `tablet`, `computer`,
    `tv` and the required `other` ("this iPhone", "this Mac", "this device").
- **`packages/brand/kit-copy/<locale>.json`** for `de`, `fr`, `es`, `pt-BR`, `it`, `ja`, `ko` and
  `zh-Hans`, with the shape `{kitCopyVersion, locale, reviewed: false, glossaryVersion, messages}`.
  Each message is a value only.
- **`packages/brand/kit-copy/glossary.json`** gives fixed translations per locale for: license,
  license key, device, product, tier, sign in, sign out, update, download ticket and Cloud Sync.
  "Polaris Key" and `{product}` are never translated.
- **`packages/brand/kit-copy/components.json`** has the shape
  `{componentsVersion: 1, components: {<Name>: {priority, family, states: {<state>: {copy: [keys]}}}}}`.
  It covers every §4.1 component, under §4.1's names. States are kebab-case (`needs-activation`,
  `cut-short`, `device-limit`, `browser-mode`, `link-copied`, `up-to-date`).
- **`conformance/parity/copy.<locale>.json`** holds the seven core packs (D4), in SP-00's schema
  plus `reviewed: false`.

### 3.2 Generator checks (`packages/brand/scripts/kit-copy.ts`, with goldens in `packages/brand/test/`)

The generator fails on any of these:

- a key that breaks the pattern, or a kit key that starts with `core.`;
- a locale that is missing a key or has an extra one;
- an argument set that differs from `en`'s, or an argument outside the closed set;
- ICU outside D5;
- plural categories that are not exactly `Intl.PluralRules(locale).resolvedOptions().pluralCategories`;
- a kit value equal (case-folded) to a `core.copy` value: the duplicate ban;
- an `en` value containing "licence", "grant", "Retry", "machine" or "plan" (S-19 and AGENTS rule 4
  vocabulary);
- a control character or a tab, which keeps terminal output safe;
- "Polaris Key" changed in any locale;
- a `components.json` key that `en.json` lacks, or an `en.json` key that no component, part or
  `a11y` group lists.

## 4. Corpus (UK-02b)

- **Generator.** A new `tools/ui-matrix.ts` (rows plus `buildUiMatrix()`) is imported by
  `tools/sign-corpus.ts` and added to the `files` map. That adds it to the source, to
  `sdks/swift/Tests/PolarisKeyTests/Resources/v2/` and to `sdks/godot/tests/corpus/v2/`, and the
  stray guard now expects it. AGENTS rule 1's file list gains `ui-matrix.json`.
- **Shape:** `{uiMatrixVersion: 1, gate, activate, signIn, deviceLimit, devices, update, settings, paywall, theme, i18n}`.
  Each component family is an array of `{name, input, expect: {component, state, copy: [keys], actions?: [ids]}}`.
- **`input`** (only the members a row needs):
  - `product {name, shortName?, accent?, accentDark?, icon: bool}`: presentation present when
    accent or icon is set, absent otherwise;
  - `platform {os, formFactor}`;
  - `stage` (a stage-matrix outcome);
  - `gate {status: licenseStatus, graceDaysLeft?, blocked?: revoked|expired|version-too-old|version-too-new|channel-not-entitled}`;
  - `capabilities {signIn, keyEntry, deviceCode, offlineActivation, trial, restore, purchase}`;
  - `pending` (an action id, which drives the busy states);
  - `activation {result: activationResult, code?, limit?, deviceCount?}`;
  - `deviceCode {phase: starting|waiting|slow-down|ok|denied|expired|cancelled, secondsLeft?}`;
  - `devices [{name, platform, formFactor, lastSeenDays, current}]`, `browserMode`;
  - `update {action: update-matrix action, outlet?, progress? {phase, fraction}}`;
  - `config [{key, type, source: enforced|default|local|env, locked, org?}]`;
  - `account {signedIn, holder?: "account"}` (S-19: the holder is the signed-in account or
    absent);
  - `entitlement {name, entitled}` (legacy `isEntitled`);
  - `offers {available}`;
  - `error {code}`.
- **`theme` rows:** `{input: {product, kit, preset?, colorScheme?}, expect: {accentSource: product|icon|ink|core, colorScheme: system|dark|light, icon: image|monogram}}`.
  These cover the no-icon fallback to ink, the Godot and TV dark default, and an integrator
  override winning over presentation.
- **`i18n` rows:** `{locale, key, args, overrides?, expect}`, where `expect` is the rendered string.
  The expected strings are **computed** by the generator's reference formatter over the catalog.
  The rows cover:
  - every plural category of every locale;
  - each `formFactor` case;
  - the per-key fallback from an override map;
  - a missing locale falling back to `en`;
  - a `core.*` key.
- **Generator checks.** Each row must:
  - name a component and state that exist in `components.json`;
  - list in `expect.copy` every static key of that state, and only keys that exist in `en.json` or
    `copy.en.json` (`core.codes.<code>.{title,message}`, `core.gate.<status>.…`,
    `core.activation.<kind>.…`, `core.fallback.…`);
  - use enum values that exist.

  In addition, every **must** component's every state must have at least one row, and every family
  must be non-empty. **Expected size:** about 150 component rows, 15 theme rows and 60 i18n rows.

- **Runners.** Not in this package. Each core reads the version and iterates the families it
  implements. The `@pkey-feature ui.<x>` test must load `"ui-matrix.json"` in a string literal and
  name the family (parity rule 2).
- **Drift gate:** `pnpm gen:corpus -- --check`. Docs: `contribute/corpus.md` gains a `ui-matrix.json`
  section; `pnpm --filter @polaris-key/docs gen` refreshes `reference/parity.mdx` and
  `reference/corpus.mdx`.

## 8. Risks

- **Compose Resources and `zh-Hans`.** The qualifiers may not take a script subtag; `zh-rCN` is the
  fallback. UK-09 confirms the qualifier and, if needed, changes only the generator's mapping.
- **`.xcstrings` in SwiftPM** needs a Swift 5.9+ toolchain on every CI lane that builds
  `PolarisKeyUI`. If one cannot compile it, emit `<locale>.lproj/Localizable.strings` and
  `.stringsdict` from the same data instead. The decision belongs to UK-02a, with no change to the
  plan's sources.
- **Machine translations** (`reviewed: false`) ship in kits. Mitigation: the glossary, the
  generator's checks and the release follow-up review (owner decision).
- **Generic family names** (`gate`, `update`) make parity rule 2's whole-word check weak. The
  required `"ui-matrix.json"` literal carries the real check.
