## 0. Owner decisions encoded (binding)

- **SDK parity pass (2026-10-05):**
  - Q6: SDKs never build portal URLs, and no `portal-links.json` URL corpus is created.
  - Q7: `commerce.receipt` is required on Node and Python.
  - Q2: Python UI is Qt plus the terminal, with no Tk kit.
  - Q3: Kotlin JVM desktop gets full parity.
  - The launch locales are content. French stays the proof locale (§3.2).
- **S-19 (model OC):**
  - A licence is an access contract and grants are entitlement reasons. The holder of account-wide
    entitlements is **the account signed in on the device**.
  - **`legacy` mode reproduces today's documents byte for byte.** Accordingly, the G11 rows (§4)
    use today's licence document shape and add no member. Per-entry `expiresAt`, `grants()` and
    401 `reason` belong to LX-17–LX-19 (W3), not here.
  - Copy says "license" (S-19 spelling rule). It never says "grant" for PX-W3's **download
    ticket** (S-19 decision 18).
- **S-16 / I-04:**
  - `license_owned` copy says that another account holds the licence, never whose account.
  - Server-supplied links stay with their owners: `manageUrl` with PX-W8 (`license.manage`),
    `signInUrl` with I-09 (`identity.keyentry`), and `accountPortal`/`openAccount()` with I-09
    (`identity.account`).
- **S-17:** `config.local` uses S-17 §5.11's names (`config.set`, `config.setting`, `onConfigChange`)
  so that U-06 and U-20 add sync state under the same API. It is device-local only.
- **S-18:** SP-00 adds no setting.

## 1. Summary

- **Ten parity ids** are added to `conformance/parity/features.json` (§3), and every SDK declares
  each one honestly, as `planned` or as an allowed `na`.

  No existing transcript changes.

## 4. Corpus

The generator is `tools/sign-corpus.ts`, and its mirrors are
`sdks/swift/Tests/PolarisKeyTests/Resources/v2/` and `sdks/godot/tests/corpus/v2/`, which both
change. `corpusVersion: 2` stays.

- **`gate-matrix.json` → `entitlementRows`.** Each row is
  `{name, gate, license, entitlement, expect: {status, isEntitled}}` over today's document shape.
  The rows are:
  - ok → true;
  - grace → true;
  - expired past grace → false;
  - revoked (`lastSyncUnauthorized`) with `dlc` enforced `true` → **false** (G11);
  - needs-activation → false;
  - not-applicable with no document → false.

  The generator asserts that `isEntitled` equals `isUsable(status) && value === true`, using
  `client-core`'s `isUsable`.

- **`feed-url-matrix.json`** (new; add it to the AGENTS rule 1 list).
  - **Input:** the `update.endpoints` templates from the discovery fixture the transcripts use,
    plus `{kind, channel?, velopackChannel?, buildId?}`.
  - **Kinds:** `appcast`, `winsparkle`, `velopack`, `appInstaller` and `zsync`.
  - **Expected:** the URL, or `{unsupported: "product"}` for a missing template.
  - **Edge rows:** alias channels such as `staging`→`beta`, and a percent-encoded channel.
- **Drift gate:** `pnpm gen:corpus -- --check`. It also fails on a stray file in either mirror.
- **Runners:** each SDK's runner checks the version number and iterates `rows` only. The implementer
  confirms this in each one (Node `conformance/runners/node`, Python, Swift, Kotlin `GateMatrixTest`
  and Godot). A runner that rejects an unknown top-level key is the one exception SP-00 may widen,
  and it must not skip any row.

**Transcripts** are recorded in `packages/worker/test/transcripts/scenarios/`, by `license.ts`,
`devices.ts`, `release.ts` and a new `distribution.ts`. `pnpm gen:transcripts` writes both mirrors.
`TRANSCRIPT_VERSION` stays 1.

The recorder changes in two files:

- `client.ts` gains three actions: `boot`, `releaseFetch` and `downloadModel`.
- `format.ts` documents:
  - the widened `result` values `enroll-claimed`, `license-disabled`, `license-expired`,
    `attestation-required`, `rate-limited` and `refused`;
  - the new expect keys `code`, `bootOutcome`, `size`, `sha256`, `platforms` and `updatesPending`;
  - the new `initial.updateJournal`.

| `activate-refusals.json`           | `license.refusals` / `core.store`, `license.activate`             | `enroll_claimed`; `license_disabled`; `license_expired`; `hardware_mismatch` (409); `attestation_required` on an attesting fixture product; `rate_limited` with `Retry-After`. Each transcript applies only where its features are `implemented`, so every one is inert in all six
SDKs after SP-00. Each replayer must skip a transcript that does not apply **before** it parses the
actions. Where one does not (Node `transcriptReplay.ts`, React, Python `transcript_replay.py`,
Swift, Kotlin `TranscriptTest.kt`, Godot `suite_transcripts.gd`), SP-00 moves the filter earlier.
That is a test-only change.

**Copy** (`conformance/parity/copy.en.json` + `copy.schema.json`):

- **Shape:** `{copyVersion:1, locale:"en", fallback, codes, gate, activation}`. Each entry is
  `{title, message}`.
- **Placeholders** come from a closed set: `{code}`, `{detail}`, `{limit}`, `{deviceCount}`,

- **Seed copy** comes from Godot `pkey_ui_copy.gd`, Kotlin `strings.xml` and React `theme.ts`.

  - `activationResult` holds the §3.1 kinds in transcript (kebab) form.
- **`gen:constants` checks** (with tests):
  - `codes` keys equal `errors.json` codes;
  - `gate` keys equal `licenseStatus`;
  - `activation` keys equal `activationResult`;
  - only known placeholders are used.
- **Emitted modules:**
  - `packages/sdk-node/src/copy.generated.ts`;
  - `packages/sdk-react/src/copy.generated.ts`;

## 8. Risks

- **The `entitlementRows` proof could stay unattached.** Mitigation: the last G11 task's acceptance
  includes attaching it, and the `license.entitlements` note lists the owners.

  have the coverage gate refuse gaps rather than allow a silent fallback.

  express one, drop that step and note it in `format.ts`. The step is not to be faked.
