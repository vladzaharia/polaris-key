tidewater · Tidewater Studio
license and updates

Usage  tidewater
       <command> [options]

Build
  build
    Build the project

Commands
  export
    Export a mix

License
  activate [key]
    Add a license key (prompted,
    or piped on stdin)
  status
    Show your license, devices
    and offline time
  deactivate
    Stop using your license on
    this device and free
    its seat
  login
    Sign in with your account in
    the browser
  logout
    Sign out on this device
  devices list
    List the devices using
    your license
  devices rename
      <deviceId> [label...]
    Rename a device (no name
    clears it)
  devices deauthorize
      <deviceId>
    Remove a device and free
    its seat
  update check
    Check for a newer version
  update apply
    Download and install the
    newer version

Run tidewater <command> --help
for one command's options.
