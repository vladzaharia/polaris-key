# @polaris-key/elements

The Polaris Key UI kit as web components on Lit 3: every component of [UI-KITS.md §4.1](../../docs/design/UI-KITS.md#41-the-set-and-the-names) as a `pk-*` element, in the product's accent.

## Where it sits

The elements draw the views of [`@polaris-key/ui-core`](../ui-core) with the tokens and fonts of [`@polaris-key/brand`](../brand). `<pk-gate>` runs every screen the license calls for and renders the app inside; each other component is its own `pk-*` element. The package is private and workspace-only.

```ts
import "@polaris-key/elements"; // registers pk-gate, pk-welcome, pk-activate, …
```

```html
<pk-gate><my-app></my-app></pk-gate>
```

[UI-KITS.md](../../docs/design/UI-KITS.md) specifies a CDN build served by the Worker at `https://key.plrs.im/elements/<major>/pk.js`. The package's build (`tsc` and `scripts/emit-css.mjs`) emits `dist/` only, and the Worker has no route for that path.

- Theme with `PolarisKey.theme({…})`, `<pk-provider theme='{…}'>` or an element's `theme` property.
- Restyle with `::part(…)` and `--pk-*` custom properties.
- Build your own UI on `@polaris-key/elements/headless`, which re-exports the ui-core models.
- The shared stylesheet is `@polaris-key/elements/styles.css`, which React reuses.

## Layout

```
src/
  index.ts        entry: registers the elements, exports PolarisKey
  headless.ts     the ./headless export: ui-core's models, no DOM
  components.ts   every pk-* element, <pk-gate>, <pk-provider>
  signin.ts       <pk-sign-in>, the one sign-in form
  element.ts      PkElement, the base of every component element
  layout.ts       which copy keys land in which part
  render.ts       styled parts and the screen template
  views.ts        templates per component form
  styles.ts       the shared stylesheet
  tokens.ts       design tokens from brand
  theme.ts        the theme API
  fonts.ts        font loading
  copy.ts         copy lookup over brand's kit-copy tables
  platforms.ts    platform names for device rows
scripts/
  emit-css.mjs    writes dist/styles.css and copies brand's fonts
test/
  fixtures.ts     ui-matrix.json rows with defaults
  matrix.test.ts  every matrix row renders its view
  signin.test.ts  the sign-in form
  look.test.ts    platform names, titles and rows in the DOM
  browser/        Chromium tests: axe, scroll, keyboard, forced colors
```
