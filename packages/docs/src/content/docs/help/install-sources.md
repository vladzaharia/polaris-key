Some apps can also be installed through AltStore, SideStore, F-Droid, Obtainium, Scoop or Homebrew. Once you add an app, AltStore, SideStore, F-Droid and Obtainium find new versions themselves.

Find them under **Other ways to get it** on the app's public download page, or under **Other ways to install** in your library.

## Before you start

- These are optional. Use one if you already use that tool.
- Get the tool itself only from its own official site or a store you already use.
- Only add a source, or run a command, from the app's own download page or your library. Anything else can install something you didn't choose. See [Use the public download page](/docs/help/download/#use-the-public-download-page).
- These tools can't sign in. An app that needs a license or an account to download isn't offered through them. Download it from your library instead.

## AltStore and SideStore on iPhone and iPad

1. Install AltStore or SideStore on your iPhone or iPad.
2. On the app's download page, find **Add to AltStore** or **Add to SideStore** and select **Open in the app**.
3. Approve the source in the app.

In your library, select **Add to AltStore** or **Add to SideStore** for step&nbsp;2. On a computer, the page also shows a QR code: scan it with your phone. To add the source by hand, copy the **Source URL** and paste it into the app.

**Add to AltStore PAL** is for AltStore PAL, a separate store app. It appears only when the developer has set it up.

## F-Droid on Android

1. Install F-Droid on your Android device.
2. On the app's download page, find **Add to F-Droid** and select **Open in the app**.
3. Approve the repository in F-Droid.

In your library, select **Add to F-Droid** for step&nbsp;2. When the page lists a SHA-256 value for the repository, the link carries it for F-Droid to check. To add the repository by hand, copy the **Repository URL** and that value. If the page says no SHA-256 value is published, ask the developer first.

## Obtainium on Android

1. Install Obtainium.
2. On the app's download page, find **Add to Obtainium** and select **Open in the app**.
3. If the link doesn't open Obtainium, select **Open via obtainium.imranr.dev**.

In your library, select **Add to Obtainium** for step&nbsp;2.

## Scoop, Homebrew and other commands

Some apps list an install command under the system it is for. Copy it from the app's own download page or your library, then run it in a terminal. It installs the app, so don't run a command you don't understand. If you don't already use Scoop or Homebrew, skip this and download the file from your library instead ([Download your app](/docs/help/download/)).

## When a new version shows up

The page and its sources can take up to 5 minutes to show a new version. If the developer is releasing a new version in stages, or has paused or stopped it, the page, AltStore, SideStore, AltStore PAL, F-Droid and Scoop keep showing the previous version. Obtainium can still offer the new version. A version the developer withdraws disappears from every source.

## Check it worked

The app appears in the tool you added it to. To check a downloaded file, see [Check a download is genuine](/docs/help/check-a-download/).

## Undo

In AltStore, SideStore, F-Droid or Obtainium, remove the app or the source. For an app you installed with a command, run that tool's uninstall command, or ask the app's developer.
