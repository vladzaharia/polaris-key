**Pair with a Code** connects two devices with no account. One device shows a code and the other types it. After that, the app can share things between them, such as a file or a save, while they are on the same network.

## Pair

You both need the same app, on the same Wi-Fi network.

1. On one device, select **Show a code**. It shows eight digits, and a QR code where the app can scan.
2. On the other device, select **Enter a code** and type the digits. Or select **Scan a code** and point the camera at the QR code.
3. Both devices show who is pairing and what the app shares. Select **Pair** on both. To stop, select **Not now**.

The screen says **Paired** when you both agree. If only one of you agrees, nothing is saved. A code works for five minutes.

## Tries left

The person who types gets two tries on a code. After a wrong code the app keeps the first two digits for you to retype, and may say **1 try left**.

When no tries are left, or the app says **Too many tries**, ask the other device for a new code. On that device, select **Show a new code**, then type the new one. Retyping the old code does not help.

The device that shows the code changes it after each wrong try. After too many tries it waits 30 seconds before it shows another one.

If the app says **Too many tries** again, or **Pairing is being blocked**, someone nearby may be guessing codes, or something on the network keeps cutting the connection. Check who is around, or try another network.

## Forget a device

1. Open the app and find **Pair with a Code**, or its list of paired devices.
2. Select the device, then **Forget**. To change its name, select **Rename**.

The other device is no longer paired with this one, and anything half sent stops. To pair again, start with a new code. You can forget a device even when pairing is off.

A device on another network shows **Nearby only**. It cannot be reached until you are on the same network again.

## If it does not work

- **Can't find the other device.** Check that you are on the same Wi-Fi network, and allow the app to find devices on your local network. See [Nearby Devices](/docs/help/nearby-devices/).
- **No room for another pairing.** Forget a device you no longer use.
- **Pairing with a code is off for this app.** The app's developer has not turned it on, or it is not available yet. Nothing is wrong with your device. [Get help with an app](/docs/help/contact/).

Pairing with a signed-in friend works differently: see [Pair with Someone Nearby](/docs/help/pair-with-someone-nearby/).
