An app that can update shows a prompt when a newer version is available. The words can differ from app to app. On a Mac, buttons use capital letters, such as **Update Now** and **Restart Now**.

## Before you start

An update restarts the app, so save your work first.

## Update from the app

1. Open the app. It can look for a newer version when it starts, and may show **Looking for a newer version…**.
2. To look right away, choose **Check for updates** in the app's menu or settings. On macOS it reads **Check for Updates…**.
3. When a newer version is available, select **Update now**.
4. When the app says the new version is ready, select **Restart now**.

You may also see:

- **Restart when ready** (**Install and Relaunch** on macOS) restarts the app once the download is ready.
- **Later** (**Remind Me Later** on macOS) closes the prompt.
- An update that fixes a security problem says **This update includes an important security fix.**
- Some apps have **Update automatically** under **Updates** in their settings.

## When an update is required

**Update required** means the app can't continue until you install a newer version. Select **Update now** or **Update**. A message that starts **Update to keep using** has no **Later** button.

The app keeps working if it says **This version is no longer supported** and **No update is available here yet.** Check again later.

## Apps from a store or package manager

A store or package manager installs updates for the apps you got from it. The app shows where.

| If the app shows                                                                                                                                                 | Do this                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Update on the App Store**<br>**Update on Google Play**<br>**Get it on Steam**<br>**Open AltStore**<br>**Open TestFlight**<br>**Open** and a store's name       | Open it and update the app there.                                                                |
| **Steam installs it. Restart Steam if it hasn't arrived.**<br>**Windows installs it the next time** the app **starts.**<br>**Reload the page to get it.**        | Do what the line says. For the Windows line, restart the app.                                    |
| **The itch app installs it.**<br>**Your software center installs it.**<br>**Your package manager installs it.**<br>or any other line that says where it installs | Update the app the way you installed it.                                                         |
| **Run** a command **to install it.**                                                                                                                             | Run the command the app shows, in a terminal. Not sure? Update the app the way you installed it. |

## Why you may not see an update yet

A developer can release an update to some people first, and a store can release in stages too. A security fix, or an update the app requires, skips the wait. If the developer pauses a release, apps stop offering it. The download page offers only a release that is open to everyone.

## If an update doesn't work

If the last update didn't start, some apps put the previous version back and say **The last update didn't start, so the previous version was restored.**

| You see                        | What it means and what to do                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| **Can't update here**          | The app can't replace its own files here. Update it the way you installed it.                   |
| **Update not finished**        | The update couldn't be applied. Close the app and open it again. It tries again when it starts. |
| **Paused · waiting for Wi-Fi** | Connect to Wi-Fi, or select **Download now**.                                                   |
| **Couldn't download**          | Select **Try again**.                                                                           |

## <a id="the-download-page"></a>Download a newer version yourself

To install a newer version yourself, download it again from your library or the app's download page. See [Download your app](/docs/help/download/).

## Check it worked

Choose **Check for updates**. The app says **You're up to date**.
