Your recovery code unlocks your synced data on a new device, in an app that encrypts it. Each app has its own code.

<Callout type="caution" title="Important">
  Only type your recovery code into the app. No one from Polaris Locker or the
  app's developer asks for it, by email, chat, phone or on a web page. Anyone who
  asks is trying to read your data.
</Callout>

## Save your code

The app shows the code once, on **Save your recovery code**: when it first sets up sync, and each time you get a new code. The code is 8 groups of 4 letters and numbers.

1. Select **Copy code**, or write the code down.
2. Keep it in a password manager or another safe place.
3. Check **I've saved my recovery code**, then select **Done**.

Polaris Locker doesn't keep a copy and can't show it again.

## Use it

On a new device, the app says **Sync is locked**. Select **Unlock sync** and enter the code. See [Unlock sync on a new device](/docs/help/sync-new-device/).

## Get a new code

If you lost your code, use a device that is still signed in and unlocked.

1. On that device, choose **New recovery code** in the app.
2. Save the new code the way you saved the first one.

The old code stops working, and you get an email, [recovery code changed](/docs/help/emails/#recovery-code-changed).

If you have no unlocked device, you can't get a new code. [Start over](/docs/help/sync-new-device/#start-over) instead.

## If you get an email you didn't expect

The email [Recovery started](/docs/help/emails/#recovery-started) means a device signed in to your account used the code. If it wasn't you, remove that device under **See your devices**, then [secure your account](/docs/help/secure-your-account/). The code works only on a device signed in to your account.
