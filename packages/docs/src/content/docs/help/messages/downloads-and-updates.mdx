Find the title an app, or your library at key.plrs.im, showed when a download or an update did not work. When your library can't start a download, it shows **The download didn't start** with a line under it. If that line is about the file or your license, it is one of the last four messages on this page. In a file list, **Not included** comes with a reason, such as **Needs an active license** or **Your license doesn't include this version**.
