## Messages for the app's developer

The app's developer has to fix these. If a message asks you to try again, do that first. If it keeps coming back, tell the developer the title, the code and what you were doing. A few of these appear only in the developer's own tools.

<DeveloperOnly />

To ask the app's developer, look for **Need help?** on the app's page in your library at key.plrs.im. Say which message you saw, and never send anyone a full license key.
