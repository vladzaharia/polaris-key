## Messages for the app's developer

The app's developer has to fix these. First do what the message asks, such as trying again, updating the app or reinstalling it. If it keeps coming back, tell the developer the title, the code and what you were doing. Not sure how to reach them? See [Get help with an app](/docs/help/contact/). A few of these appear only in the developer's own tools. If you see **Insecure connection**, the app refused it, so nothing was sent over it.
