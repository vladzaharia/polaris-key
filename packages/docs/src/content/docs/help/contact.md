Who to ask depends on the problem: the app's developer, the store you bought from, or Polaris Key.

## Start with the app's help card

On an app's page in your [library](https://key.plrs.im), look for **Need help?**. When the app's
developer has provided support details, the card says that the developer handles licenses and
downloads for that app. It can show:

- a button that starts with **Contact** and names the developer
- a button that starts with **Email** and shows an address
- a link that shows the developer's website

If the card is not there, Polaris Key has no app-support contact for that app. Check the app or
store where you got it.

## Contact the app's developer

Contact the app's developer for a problem with the app, its license, or downloads. If you bought
the app directly from the developer, ask them about billing or a refund too.

## Contact the store

If you bought the app through a store, use that store's purchase help for payment, billing, or a
refund.

## Contact Polaris Key

Polaris Key handles your account, signing in, and privacy. It does not have a published public help
address. If your sign-in code did not arrive or has expired, select **Send a new code** on the code
screen. If a security email worries you, choose **Secure your account** in it. For an app's
features, billing, or refund, use the developer or store.

## Include only what is needed

Name the app, your device, and what happened. Include the message you saw if it helps explain the
problem. Do not send a full license key.
