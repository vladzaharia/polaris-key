Use this Help site when an app uses Polaris Key for access, its library, or downloads. Start with
the task that matches what you need. An app shows only the options its developer has chosen for it.

## Popular tasks

- [Activate your app](/docs/help/activate/) — start using an app with a license key, sign-in, a
  free option, or a supported store purchase.
- [Device limit reached](/docs/help/devices/) — make room for the device you want to use.
- [Move to a new computer](/docs/help/devices/) — use an app on another device.
- [Download your app](/docs/help/download/) — find the download for an app in your library.
- [Your code didn't arrive](/docs/help/emails/) — request a new code for a sign-in you started.
- [Refunds](/docs/help/contact/) — find out whether to ask the developer or store.
