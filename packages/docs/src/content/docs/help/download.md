You can download an app from your library at [key.plrs.im](https://key.plrs.im) or from its public download page. Your library is the list of your apps there. Polaris Key is the service the app uses for licenses, sign-in and downloads.

## Before you start

Sign in to your library with the email that has the license. An app that anyone can download also has a public download page, which needs no account.

## Download from your library

1. Sign in at [key.plrs.im](https://key.plrs.im) and find the app.
2. Select **Download for macOS**, **Download for Windows** or **Download for Linux**. If your license covers only an older version, the button shows that version, such as **Download 2.4.1**.
3. If the app has one file for your computer, the download starts. If it has more, the button opens the app's page with a list. Choose a file and select **Download**. **Apple silicon** and **Intel** are for Macs with those chips. **Universal** runs on both.
4. The library creates the download link when you select the button, so the link is never out of date.

## Download on a phone

The library shows your phone's store, such as **Get it on the App Store** or **Get it on Google Play**. If the app has only a computer version, select **Email me the download**. The library sends a link to your account's email address. Open it on a computer and sign in.

## Other places to get the app

- **Also yours on** lists the stores that carry the app, such as Steam. A store appears only while a current version is available there.
- **Other ways to install** lists tools such as AltStore, F-Droid, Obtainium, Homebrew and Scoop. See [Install from AltStore, F-Droid, Obtainium or Scoop](/docs/help/install-sources/).
- If a file says **Get it from Steam**, or names another store or the developer, your library doesn't host that file, but your license covers it. Get it from that store or the developer.

## Use the public download page

A developer can share a page that anyone can open. Its address starts with `dl.plrs.im`.

- It leads with one button for your device, such as **Download for macOS** or **Get it on Google Play**. If it can't tell what you use, it lists every system.
- **Other ways to get it** lists other stores, buttons that add the app to AltStore or F-Droid, and install commands. **Download from Polaris Key** lists the app's files. The developer uses Polaris Key to host them.
- **All downloads** lists every file with its version, size, minimum system version and SHA-256, a code that identifies the file. **Signing keys** lists the keys the developer signs with.
- It shows the app's current public version. If the developer is releasing a new version in stages, or has paused it, the page keeps offering the previous version.
- **Nothing is available to download right now.** means the page lists no version.

## If a download doesn't work

A file your license doesn't cover shows **Not included** and a reason. The last two rows are messages an app can show.

| You see                                       | What it means                                    | What to do                                                                                    |
| --------------------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Needs an active license**                   | Your license has expired or been suspended.      | Renew or reactivate it, then try again.                                                       |
| **Your license doesn't include this version** | Your license doesn't cover this release.         | Download a version it covers, or upgrade your license.                                        |
| **Not available here yet**                    | The library can't hand over this file.           | Ask the developer for another way to get it.                                                  |
| **That file is no longer offered**            | A newer release may have replaced it.            | Reload the page to see the current downloads.                                                 |
| **Sign in to download**                       | An app couldn't confirm that you have a license. | Sign in or activate a license, then try again. See [Activate your app](/docs/help/activate/). |
| **Download unavailable**                      | The developer hasn't set up this download.       | Ask the developer.                                                                            |

## Check it worked

Your browser lists the file in its downloads. To confirm that it's the file the developer published, see [Check a download is genuine](/docs/help/check-a-download/).
