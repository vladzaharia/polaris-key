An app shows only the activation options it supports. Start at its welcome screen and use the option that appears there. On a Mac, the buttons use capital letters, such as **Use a License Key**.

## Before you start

To use the app on this device, activate it in the app with one of the options below.

If the app links to your library, **Activate license** there (**Activate** on a phone) only adds a
key to your account. It does not activate this device.

## Use a license key

1. Select **Use a license key**.
2. Enter the key in **License key**.
3. Select **Activate license**.

## Sign in

Select **Sign in**, then finish the sign-in steps the app shows. This option appears only when the
app has a sign-in method available.

## Continue free

When **Continue free** appears, select it to start the app's free version. When **Start a free trial** appears, select it to start a trial. These options appear only when the app offers them.

## Activate offline

When **Activate offline** appears, select it. See [Activate a computer without internet](/docs/help/offline-activation/).

## Restore a store purchase

When **Restore purchase** appears, select it. The app checks your store account for earlier
purchases. This option depends on the app and the store, so it does not appear in every app.

## If activation does not work

- If the app says the license is on all its devices, see [Device limit reached](/docs/help/device-limit/).
- For a message about the key, see [Messages about your license key](/docs/help/messages/license-key/).
- Otherwise read [Get help with an app](/docs/help/contact/) and include the message you saw. Do not include a full license key.
