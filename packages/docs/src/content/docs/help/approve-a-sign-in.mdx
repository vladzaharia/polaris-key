Some apps can't open a web page, for example on a TV or on a game system. They show a short code
and a web address instead. You finish signing in on your phone or computer.

<Callout type="caution" title="Important">
  Only approve a sign-in you started. Someone who starts a sign-in on their own
  device can ask you for the code. Continue only when the code and the device
  name match the app you are using.
</Callout>

## Approve it

1. On your phone or computer, open the web address the app shows. If the app shows a QR code,
   scan it and skip to step 4.
2. In **Code**, enter the code from the app.
3. Select **Continue**.
4. Check that the code and the device name match what the app shows. If they don't match, close
   the page.
5. Select **Continue to sign in**.
6. Finish signing in on the page that opens.
7. Go back to the app. It signs in by itself.

## Check it worked

The app shows that you are signed in.

## If the code doesn't work

The page says **That code isn't valid or has expired. Check the code on your device.** A code
works for 10 minutes. Ask the app for a new code, then try again.

## If you didn't start it

Don't enter the code, and don't select **Continue to sign in**. Close the page. No sign-in
happens, and the code stops working after 10 minutes. If you already approved a sign-in you didn't
start, read [Secure your account](/docs/help/secure-your-account/).

## Still need help?

If the app doesn't sign in, read [Get help with an app](/docs/help/contact/).
