The console at `/manage` has a sidebar with two contexts. Platform, off any product, lists Home and the platform's pages. A product lists its own pages, then one group per feature it runs, with Settings at the foot. Switch context from the card at the top. A section's page list below is `SECTIONS` in `packages/admin/src/console/nav.ts`. A product page's address is `#/p/<slug>/<path>`, with a record id and tab after it where the page has one. The session lasts 8 hours, and the account menu shows when it ends.

## Keyboard

Shortcuts never fire while you type in a field. Press `?` for the sheet in the console.

| Keys | Action |
| --- | --- |
| `⌘K` | Open the command palette |
| `/` | Open the command palette |
| `?` | Show keyboard shortcuts |
| `g h` | Go to Home |
| `g p` | Change product |
| `⌘\` | Collapse or expand the sidebar |
| `Esc` | Close the topmost overlay |
| `g o` | Go to Overview |
| `g a` | Go to Activity |
| `g s` | Go to Settings |
| `g l` | Go to Licenses |
| `g c` | Go to Catalog |
| `g r` | Go to Releases |
| `g m` | Go to Rollouts (matrix) |
