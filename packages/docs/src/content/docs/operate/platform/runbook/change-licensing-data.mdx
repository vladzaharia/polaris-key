**Role required:** Platform admin. The owner schedules the production runs.

**Impact:** These runs change what every license document says. Nothing starts by itself; each is run by hand, in order.

Use this when a release carries one of these changes and production data has to move with it.

<RunbookSection file="RUNBOOK" heading="Offline grace clamp" />

<RunbookSection file="RUNBOOK" heading="Licensing model expand" />

## Verify

- Grace clamp: read the affected-license report before the release that turns the clamp on.
- Model expand: reads move over the following releases; check the drift report the section names before any later step.

## Roll back

- Model expand: after rolling the Worker back, run the down script `0105_licensing.down.sql` once, from the owner's session. It is idempotent.
- Grace clamp: a product can opt out in **License**, **Settings**, **Clamp offline grace to expiry**, with a reason.

## Escalate

A report that disagrees with the console, or a run that stops partway, goes to the owner before any second run.
