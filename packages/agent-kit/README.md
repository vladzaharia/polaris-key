# @polaris-key/agent-kit

The Polaris Key skills for coding agents, packaged as a Claude Code plugin named `polaris-key`. Each skill teaches an agent one job in a product's `.pkey/` directory, such as authoring the manifest or adding a catalog entry.

## Where it sits

The package is private and is never published to a registry. A release builds it into a zip and a marketplace file (`tools/agent-kit-release.ts`); the repository's own `.claude/skills/` links back to the skills here, so an agent working in this repository loads the same text a user installs.

To try the built kit in Claude Code, install the plugin from its marketplace:

```
/plugin install polaris-key --marketplace <owner>/<repo>
```

## Layout

```
.claude-plugin/
  plugin.json     the plugin manifest; it carries no version, the release stamps one
skills/
  <name>/SKILL.md one folder per skill, with its own references
package.json      private; the workspace entry only
```

- `.claude/skills/<name>` is a relative link to `skills/<name>`. The skill that leads the omniplatform program stays in `.claude/skills/`, because it is for this repository's maintainers.
- To add a skill, create `skills/<name>/SKILL.md` with `name` and `description` frontmatter, then link it: `ln -s ../../packages/agent-kit/skills/<name> .claude/skills/<name>`. Run `pnpm skills:check` after.
